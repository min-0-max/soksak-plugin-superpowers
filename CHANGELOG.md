# Changelog

[한국어](CHANGELOG.ko.md)

- S8: The workflows `ci.yml` and `release.yml` check each push and release with `make pack`.
- S7: The release build extracts the tarball with its header modes (`tar -xzpf`) and marks each `files` entry whose upstream file has an execute bit with `executable: true` (`scripts/build-release.mjs`). `group/superpowers.js` passes the member through and refuses a value that is not a boolean. Tests: `test/release-build.test.mjs` (the mark under a restrictive umask, and no mark without the bit) and `test/group-shape.test.mjs`.
- S6: The group ships only the skill folders. `group/files.js` holds the files of the release `skills/<name>` folders at `.claude/skills/<name>/<file>`, and the agent `superpowers` names `.claude/skills/using-superpowers/SKILL.md`. The plugin manifest and the hooks are not project files and are no longer shipped. `folders` lists `.superpowers/` and `.claude/skills/`. Tests: `test/release-build.test.mjs` (9 tests), `test/group-shape.test.mjs`; Red: the previous layout and the `.claude/skills/` paths failed.
- S5: The release build pins obra/superpowers `v7.0.2` (`release/upstream.json`, sha256 of the codeload tarball) and writes `group/files.js`, a data module with the skill folders, the agent `superpowers` (its main skill file) and the Claude plugin files at their upstream paths, and `group/superpowers.LICENSE`. `group()` imports the module and returns `files`; `folders` lists the upstream paths. Tests: `test/release-build.test.mjs` (7 tests), `test/group-shape.test.mjs`, `test/manifest-shape.test.mjs`; Red: the build script and `groupFrom` were missing.
- S3: The plugin exports the superpowers group from `group/superpowers.js`. `group()` returns the group object of the agents.makers interface: the corrected plugin folder, claude as the only CLI, no agent definitions, the skill folder, the `.superpowers/` project folder and the location rules for plans, specs and worktrees. The `agents.makers` item states `id` and `name`, and `package.json` ships the module. `test/group-shape.test.mjs` checks each member with literal expectations.
- S4: The `agents.makers` item states the range `^0.0.1`, the version of the point that the agents plugin declares. `test/manifest-shape.test.mjs` checks the range with a literal expectation.
- S1: The plugin declares its manifest: `dependencies` names `@soksak/plugin-agents`, and `contributes` holds one item of `agents.makers` with `range` and `module`. The plugin declares no surface, sections, sidebars or data. `test/manifest-shape.test.mjs` checks the members of `plugin.json` and `package.json` with literal expectations. `engines.soksak` is `^0.0.46`, the core version whose specification defines `contributes`. The version is 0.0.0, because no release is made yet.
