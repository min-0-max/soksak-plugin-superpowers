- [o] S7 — P1, S5를 따른다: Group이 upstream의 실행 가능한 파일을 표시한다. Input: release build는 tarball을 header mode 없이 풀므로, tar header mode에 실행 bit가 있는 upstream 파일(예: `skills/brainstorming/scripts/run.sh`)이 실행 bit 없는 text 항목으로 가져오기에 전달되고, 가져오기는 그 파일을 실행 bit 없이 쓴다. Expected: build는 header mode로 풀며(`tar -xzp`), build의 umask는 이를 바꾸지 않는다. 실행 bit가 있는 upstream 파일의 `files` 항목은 `executable: true`를 가지고, 다른 항목은 member가 없다. `groupFrom`은 member를 넘기고 boolean이 아닌 값을 거절한다. Red: 변경 전 `node --test test/`는 2개 case가 실패했다. Build는 실행 가능한 파일을 표시하지 않았고, `groupFrom`은 member를 버렸다. 실행 bit가 없는 case는 guard로서 변경 전에도 통과했다. Result: build는 `tar -xzpf`로 풀고 header mode에 실행 bit가 있는 항목을 표시하며, `groupFrom`은 member를 넘기고 boolean이 아닌 값을 거절하며, `node --test test/`가 test 34개를 통과한다. `-p` 없이 풀면 제한적인 umask가 풀린 파일의 실행 bit를 지우므로, 표시를 검사하는 test는 umask 077 아래에서 build를 실행한다.
